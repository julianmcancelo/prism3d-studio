Split 3D Models by Color

Click a color region on a painted 3D model and that color comes away as its own part. The cut faces are closed, so for 3D printing you can print each color on its own in its own filament and then assemble the parts.

How to use

  1. Upload a painted 3D model, or press Try Pingu.
  2. Click the color region you want to split off.
  3. Press Space or Split.
  4. Repeat as needed. Splits can be undone, latest first.
  5. Download the parts as 3MF or STL.

Tips

  • If a boundary looks jagged, tidy it first with Smooth boundary.
  • Turn on Split in place to keep every part where it was in the model.
  • Turn on Add connectors automatically to add a connector to every new cut face.

FAQ

Can I split an STL file by color?

STL files carry no color. Paint the model first with Paint, then split it.

It says the color parts are already separate.

The 3D model was saved with each color as a separate piece. Join them with Create one colored model in Repair & simplify, then split.

Are the cut faces of the parts left open?

No. Cut faces are filled, so the parts are ready for 3D printing.
